STL Evaluator
=============

This project uses [StlEval](https://gitlab.com/abakhirkin/StlEval).
Appended with a Python.


run.py will find the heartrate, scale and run the STP formulas, create the .csv files, find the baseline DP and PI values and then compute the delta PI for the selected case in the data folder.

plot1.py will show the MAP, Avg MAP, and TTH < min warnings within a given window.

plot2.py will show the diastolic, systolic and dicrotic notch within the given window.

plot3.py will show the MAP, Avg MAP, and TTH < min warnings, the Perfusion Inded, Delta PI from baseline, Relative dicrotic Notch Height and Delta DP within a given window.
