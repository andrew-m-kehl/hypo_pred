
Usage: stle ([OPTIONS] SIGNAL_FILE)+  (command-line mode)
   or: stle cmd [OPTIONS]             (interactive command mode)
   or: stle help [TOPIC]              (help mode)
 

Command-Line Mode
-----------------

In command-line mode, stle reads one or more signal files and evaluates one or
more formulas, as given by the arguments.

A SIGNAL_FILE is a CSV file that contains a sequence of samples. Every line
corresponds to one sample and contains a timestamp and values of one or more
signals (separated by commas). How exactly the CSV file is interpreted is
controlled by the option '-isf'.
If SIGNAL_FILE is '-', the signal is read from stdin.

For the description of formula syntax run `stle help formula`.
        
Options are:
-f FORMULA    Evaluate the FORMULA. Do not forget double quotes as necessary.              
-ff FILE      Read a formula from the file. If FILE is '-', read fromula from
              stdin
-isf FORMAT   Specifies how to translate samples in the following CSV files
              to a sequence of intervals.
    FORMAT is a string of characters:
    f    Default. Sample time is in the first column.
    l    Sample time is in the last column.
    s    Default. A sample denotes start time of an interval. First sample
         should have time 0.
    e    A sample denotes end time of an interval.
    o    Default. Intervals except the last are right-open.
    c    Intervals are right-closed.
    Format 'eo' is special: the sample at time 0 (if it exists) and the last
    sample are inclusive.
    Different formats can be specified for different files, e.g.,
    `stle -isf feo file1 -isf lso file2 ...`.        
-or 0|1       Default 0. Output robustness instead of satisfaction. Only
              works for standard STL formulas.
-r            Same as '-or 1'.
-os 0|1       Default 0. Print whole output signal instead of only value at
              time 0 (this may print a lot).        
-osf FORMAT   Print singnals in specified format.
    FORMAT can be:
    c    Default. Csv format that can be read with '-rf feo'.        
    g    Format for visualizing with Gnuplot.
    d    Human-readable format for debugging.
-osn TITLE    Title of the output signal (Gnuplot format only).
-pf      Print the formulas to stderr. Every formula is printed twice: before
         and after rewriting.
-pi      Print the input signal to stderr in debug format (this may print a
         lot).
-pc      Print performance counters to stderr.
-pm      Print some extra messages for readability.
-de 0|1  Default 1. If 0, do not evaluate the formulas.
-db 0|1  Default 0. Read whole signal file into memory before (speeds up
         reading a bit in Windows).
-v       Print version information and exit.
-h       Print this message and exit.


Interactive Command Mode
------------------------

In interactive command mode, stle reads commands from stdin and writes output
to stdout. Run `stle help cmd` for more details.


Help Mode
---------

In help mode, stle prints a brief help on a topic.
Run `stle help` for a list of topics.
